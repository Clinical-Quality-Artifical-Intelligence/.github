## 👋 About Us

**Clinical Quality Artificial Intelligence** is a UK-based open-source organisation founded by **Lincoln Gombedza**, Registered Learning Disability Nurse (RNLD) and Practice Educator.

We champion the **"Nurse as Citizen Developer"** movement — empowering nurses and nursing students to build, use, and understand AI-powered clinical tools without needing a computer science degree. Every tool we build is free, requires no API keys (unless stated), and is deployable to Hugging Face Spaces in minutes.

> 💡 *"Technology built by those who understand the ward is technology that works on the ward."*

---

## 🎯 Our Mission

> To make high-quality, evidence-based digital tools freely available to every nursing student and registered nurse in the UK — and beyond.

| | |
|-|-|
| 📚 | **Enhance nursing education** with interactive, evidence-based learning tools |
| 🏥 | **Support clinical practice** with decision-support and reference tools |
| 🤖 | **Advance AI literacy** in nursing through hands-on, accessible technology |
| 🌈 | **Promote health equity** by removing cost and access barriers |
| 🔓 | **Stay open source** — transparent, collaborative, community-driven |

## ⚡ Quick Start — 60 Seconds

No login. No API key. No setup. Pick any tool and launch it directly on Hugging Face Spaces:

```
1. Click any 🤗 badge below
2. The Streamlit app loads in your browser
3. Start learning / practising immediately
```

> All tools are hosted on [Hugging Face Spaces](https://huggingface.co/NurseCitizenDeveloper) and run entirely in the cloud. A modern browser is all you need.

**Want to run a tool locally or contribute?**
```bash
git clone https://github.com/Clinical-Quality-Artifical-Intelligence/<repo-name>
pip install -r requirements.txt
streamlit run app.py
```

## 🔬 FHIR & Interoperability

<details>
<summary><strong>Open Nursing Core Implementation Guide — FHIR R4</strong></summary>
<br>

The **[Open Nursing Core IG](https://github.com/Clinical-Quality-Artifical-Intelligence/open-nursing-core-ig)** is a foundational FHIR Implementation Guide that formalises the nursing process (ADPIE) as interoperable, standards-compliant healthcare data.

| Profile | Description |
|---------|-------------|
| `NursingAssessment` | Structured clinical assessment aligned to ADPIE |
| `NursingDiagnosis` | NANDA-I–aligned nursing diagnosis resource |
| `NursingCarePlan` | Goal-directed care planning with SMART objectives |
| `NursingIntervention` | Evidence-linked nursing interventions (NIC-aligned) |
| `NursingOutcome` | Measurable care outcomes (NOC-aligned) |

Built with **FHIR Shorthand (FSH)**, published via **SUSHI**, and validated against the HL7 FHIR R4 specification. Aligned with NHS Digital FHIR UK Core.

[![FHIR](https://img.shields.io/badge/FHIR-R4-E8523A?style=flat-square)](https://hl7.org/fhir/R4/)
[![NHS UK Core](https://img.shields.io/badge/NHS%20UK%20Core-Aligned-005EB8?style=flat-square)](https://simplifier.net/hl7fhirukcorer4)
[![Licence](https://img.shields.io/badge/Licence-MIT-green?style=flat-square)](https://opensource.org/licenses/MIT)
